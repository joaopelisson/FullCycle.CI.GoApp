## 🇺🇸 English

This repository is part of the **Continuous Integration (CI)** track from the **@FullCycle** and aims to **demonstrate, in a practical and end-to-end way, how to use GitHub Actions as a CI pipeline** for a Go application.

The project is **finished** and serves as a **reference repository** for CI best practices, workflow organization, and automation using **YAML-based GitHub Actions workflows**.

---

### 🎯 Repository Purpose

To showcase how to design and run **CI pipelines with GitHub Actions**, covering real-world scenarios such as:

- Automated builds
- Running tests in isolated environments
- Using **matrix strategy** (multiple Go versions)
- Building Docker images
- Automatically publishing images to **Docker Hub**
- Enforcing CI checks on **Pull Requests**

All steps are **fully automated via GitHub Actions**, without relying on external CI tools.

---

### ⚙️ Key Concepts & Approaches

- **Matrix Strategy**
  - Pipeline execution across multiple Go versions
- **Build & Test**
  - Application build
  - Automated test execution
- **Docker**
  - Docker image build
  - Automatic publish to Docker Hub
- **Pull Request-based CI**
  - Automatic validation before merge
  - Required status checks
